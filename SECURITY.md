# Security

Mulder is a public preview. Use it only for read-only operations that your API already protects.

## Report a problem

Use the private security advisory form for this repository. Do not open a public issue for a possible security problem.

Include the affected version, the smallest reproduction, the expected result, and the actual result. Remove API keys, personal data, and private URLs.

## Product limits

Mulder does not replace authentication or access checks. It cannot verify which browser agent made a call. It does not generate tools that change data. Read the website security guide and `SUPPORT.md` before you use it.
